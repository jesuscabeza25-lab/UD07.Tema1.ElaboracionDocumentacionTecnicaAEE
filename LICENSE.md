 **1\. Apache Guacamole**  
Proporcionar acceso de escritorio remoto a través del navegador (cliente sin cliente).  

\-Licencia: Apache License 2.0 (Licencia permisiva).    
\-Fuente Oficial: [https://guacamole.apache.org/](https://guacamole.apache.org/)

**2\. OpenSSH**  
Servidor especializado para prácticas de administración remota segura y criptografía de clave pública.  

\-Licencia: Licencia tipo BSD (Licencia permisiva).    
\-Fuente Oficial: [https://www.openssh.com/portable.html](https://www.openssh.com/portable.html)

**3\. PostgreSQL**  
Gestión de la base de datos interna para el almacenamiento de configuraciones y usuarios. 

\- Licencia: Licencia PostgreSQL (licencia de tipo open source similar a BSD o MIT).  
\-Fuente Oficial: [https://www.postgresql.org/about/licence/](https://www.postgresql.org/about/licence/)

**4\. Docker**  
Motor de contenedores para el despliegue de la infraestructura aislada y estanca.  

\-Licencia: Apache License 2.0.  
\-Fuente Oficial: [https://www.docker.com/legal/docker-terms-service/](https://www.docker.com/legal/docker-terms-service/)

**5\. Linuxserver/Webtop (Ubuntu XFCE)**  
Contenedor que proporciona el entorno gráfico ligero accesible por RDP y Web.  

\-Licencia: Principalmente GNU GPL (al basarse en Ubuntu/XFCE), aunque las imágenes de Linuxserver se distribuyen bajo licencias libres.  
\-Fuente Oficial: [https://github.com/linuxserver/docker-webtop](https://github.com/linuxserver/docker-webtop)

Se han seleccionado estas piezas de software por permitir un ahorro de costes (TCO) al evitar licencias propietarias recurrentes, permitiendo reinvertir ese capital en la seguridad del sistema.
